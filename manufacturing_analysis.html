Manufacturing Data Integration & Operational Analysis¶

This project integrates machine operating data, supplier characteristics, production-batch information, and product test results to investigate patterns associated with manufacturing performance. The analysis examines differences across machines, suppliers, and production batches before using unsupervised clustering to identify operating-condition profiles associated with substantially different product failure rates.

Project Objective¶

The objective is to combine multiple manufacturing data sources into a unified analytical dataset and determine which production characteristics are most strongly associated with differences in product test outcomes.

Data¶

The analysis integrates five datasets:

  • Three machine datasets containing production-batch and operating measurements (x1, x2, x3, and x4)
  • Supplier data containing supplier and material-density information for each production batch
  • Product test results containing pass/fail outcomes for tested products

The datasets are integrated using production batch and individual product identifiers.

Tools & Methods¶

Python • Pandas • Matplotlib • Seaborn • scikit-learn • KMeans Clustering

Methods include data integration, exploratory data analysis, correlation analysis, failure-rate analysis, feature standardization, KMeans clustering, and silhouette analysis.

The analysis begins by loading production data from three manufacturing machines. Each dataset contains batch identifiers, cell phone case colors, and four operating variables (x1 through x4).

The datasets are first examined individually to understand their structure, data quality, distributions, and differences in operating behavior. The analysis then compares production batches and operating variables across the three machines before combining the datasets for further analysis.

Selecting the Number of Clusters¶

Candidate cluster solutions were evaluated using both inertia and silhouette score. Inertia measures how tightly observations are grouped within clusters and is commonly evaluated using the elbow method. Silhouette score measures how well observations fit within their assigned cluster relative to neighboring clusters, providing an additional measure of cluster separation.

Clustering Analysis Summary¶

The clustering analysis identified eight distinct operating-condition profiles using only the four machine operating variables. Cluster selection was supported by both inertia and silhouette analysis, with the eight-cluster solution achieving the highest silhouette score among the candidate models evaluated.

When test outcomes were examined after clustering, failure rates differed substantially across the resulting groups, ranging from 3.5% in Cluster 3 to 94.6% in Cluster 6. Because test outcomes were not used to create the clusters, these differences provide evidence that naturally occurring combinations of machine operating conditions are meaningfully associated with production performance.

Key Findings and Operational Implications¶

This analysis integrated machine operating data, supplier characteristics, production-batch information, and product test results to examine potential drivers of manufacturing performance.

Key Findings¶

  • Machine performance was relatively similar overall. Failure rates ranged from 67.7% to 72.2% across the three machines. Machine 3 had the highest failure rate despite having fewer tested observations, demonstrating the importance of comparing rates rather than raw failure counts.

  • Supplier differences were more nuanced than raw counts suggested. Supplier A produced more failures in absolute terms because it had more tested observations, while Supplier B had the higher failure rate at 74.5% compared with 67.0% for Supplier A. Supplier A also exhibited substantially greater variability in material density, although average machine operating conditions remained broadly similar across suppliers.

  • Production batch showed the greatest variation in test outcomes. Batch-level failure rates ranged from 0% to 100%. Several batches experienced either complete failure or no observed failures across multiple machines, suggesting that batch-level characteristics warrant particular attention when investigating production performance.

  • Operating-condition profiles were strongly associated with test outcomes. Unsupervised clustering identified eight distinct operating profiles with failure rates ranging from 3.5% to 94.6%. The lowest-failure cluster combined below-average x1 and x3, near-average x2, and substantially above-average x4, while the highest-failure cluster exhibited elevated x1, x2, and x3 with below-average x4.

Operational Implications¶

The results suggest that manufacturing failures are unlikely to be explained by machine or supplier identity alone. Batch-level characteristics and combinations of machine operating conditions appear more closely associated with differences in product test outcomes.

In a production environment, these findings would support further investigation into the characteristics of high- and low-performing batches and the operating-condition ranges represented by the lowest-failure clusters. Additional controlled analysis would be required before treating these relationships as causal or using them to establish production settings.
