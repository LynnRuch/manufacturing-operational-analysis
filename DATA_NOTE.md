# Data Availability

The source datasets used in this analysis were originally provided as part of academic coursework.

Because public redistribution rights for the original CSV files have not been established, the source data are intentionally excluded from the public repository.

The notebook documents the structure of the datasets, the integration process, the analytical methods, and the resulting outputs so the project can still be reviewed without redistributing the original course-provided files.

If redistribution permission is later confirmed, this note can be updated and the appropriate datasets can be added to the repository.
